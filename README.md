# 牛马奋斗录

五场景像素风生存游戏。每局坚持 3 分钟，局末选择下班或继续加班；第五局结束固定进入“加班猝死”结局。

## 运行与验证

```bash
npm install
npm run dev
npm run build
npm run test:smoke
```

本地开发页默认使用 `http://127.0.0.1:5173/`。`test:smoke` 会自行启动临时 Vite 服务，检查五场景、结局、暂停四画面、Buff 叠加、后按方向优先、音效开关和手机布局；需安装 Playwright Chromium，或在 macOS 使用系统 Google Chrome。

## 场景与操作

场景依次为办公室、会议室、茶水间、公司前台、老板办公室。五场景使用统一人物尺寸与可行走净空地板；背景家具不生成碰撞障碍。可使用 `?scene=office`、`meeting`、`pantry`、`reception`、`boss` 固定预览背景和活动边界。

- `W/A/S/D` 或方向键移动；同时按住一组相反方向时，以后按下的方向为准。手机横屏使用屏幕方向键，规则相同。
- `Space` 或 `Esc` 暂停；手机使用右上角暂停键。
- 背锅、吃饼变胖、红温可同时生效并叠加形象；每口黑锅都会加入背后锅堆，锅堆不设高度上限，可以超出画面。背部朝向甲方激光可挡住攻击并清除负面状态，但格挡范围始终只按第一口锅计算。
- 男女角色各有四帧移动动作；脚步、投掷、命中、暂停等事件有对应合成音效。暂停按当前主角分别展示厕所或工位画面，单次暂停满 60 秒切换到对应翻车画面；女主角厕所画面为整扇关闭的隔间门，仅显示门下的脚和鞋。
- 甲方先锁定玩家当时所在的水平轨迹，显示 0.5 秒预警线与准星，然后沿该固定轨迹发射 1 秒；预警期间移开即可躲避，发射后不追踪玩家。
- HUD 音符按钮切换音效；浏览器首次点击开始游戏后才会启用声音。
- 成就按达成难度分为 S / A / B / C；普通结算按“工牌 → 成就框 → 雷达图”展示并可下载长图，猝死结局不显示雷达与过程成就。

场景坐标、美术说明见[五场景游戏地图](牛马奋斗录_五场景设计.md)，规则见[游戏设定](牛马奋斗录_游戏设定.md)。
